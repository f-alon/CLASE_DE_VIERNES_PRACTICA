El archivo hoja_funciones.py contiene funciones genericas para realizar distintos calculos como por ejemplo:

  * funcion para sacar raiz cuadrada de un numero recibe un numero n como parametro
  * funcion mas que generica que calcula el volumen de un cilindro: (recibe el radio y la altura como parametros)
  * funcion generica para calcular el perimetro de un rectangulo
  * Funcion generica que permite determinar el área y perímetro de un triángulo equilátero
  * funcion generica para calcular el Area de un triangulo escaleno(usar si se conoce un lado (b) y la altura (h) asociada a dicho lado)
  * Funcion generica para calcular radio inscrito (circulo interior) de un triangulo escaleno. Recibe dos parametros: a = el area del triangulo y s = el semiperimetro, que se calcula sumando los tres lados y dividiendo entre 2
  * Funcion generica para calcular radio circunscrito (circulo exterior) de un triangulo escaleno. (recibe como parametro las longitudes de los tres lados y el area total del triángulo)
